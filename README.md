# English Unit 1

Interactive revision site for English Unit 1 (3rd grade): alphabet, numbers 1–100, days, months, "about me", verb *to be*, animals & adjectives, It's / They're, Is it…? / Are they…?, prepositions of place.

Each topic has three tabs:
- 📖 Theory — text in English, Russian and Catalan with ▶️ read-aloud (browser Web Speech API);
- 📝 Exercises reproducing the school workbook;
- ⭐ New practice exercises on the same patterns.

Single file `index.html`, no build step. Enable GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
